## Decisions
- No setup code. A fresh instance is live at any address; account creation is step 1 of the wizard.
- Open mode stays like Sonarr's "Disabled for Local Addresses": no password on local networks and tailnets. One rule, no
  separate `open_lan` setting. Forwarded headers never count. No trusted-device or approve-code design.
- 0.5.0 never ships as stable; soak over. Next release 0.6.0-beta.1.
- Docs are generic ("your server"); the owner's own deploy steps live in one runbook.
- Offline-opened articles record no reading time (unchanged). No weekly govulncheck/Trivy job (owner's "no monitoring" line).
  No new env opt-in for `allow_private_net` (design says no new config surface); document the claim risk instead.
