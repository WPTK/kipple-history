## General/PC
* Fonts should update upon selection, not refresh. 
* I can see radio buttons when I click on text size, density, or reading spacing
	* Can we come up with a better word or industry standcard phrase for "reading spacing"? It's confusing 
* The toast for "x new articles" is not smooth, it seems very janky. 
* Selecting any slider button in the settings forces the page to move up and everything goes off screen. It's odd behavior. You have to scroll up. Some of them are also difficult to click, it's like they might jump a tiny amount. 
* Headlines can be renamed "Email - Compact" or something, that's basically the same theme. In future updates we can look at how to make this look more an inbox in both views. 
* The categories "sports" "books" "tech-AI" should all be collapsable. I don't want to have to scroll through all the categories to get the ones I want
* There should be a "favorite" option for categories too, so I can move them to the top (or allow me to freely rearrange and visually demonstrate somehow that the move is permanent visually
* "Feed Health" can go inside the "Manage Feeds" menu option. Well, I see it's already there under the three dots button -- remove it from the sidebar.  
* Settings was hard for me to find. I kept wanting to look by the layout. This could just be that I'm unfamiliar with it. 
* "Unread" doesn't seem to do anything. It marks it as unread visually, but still appears in the "Unread" tab/menu. 
* For the layout options, instead of a seperate menu for "device default", make a star or something next to each one that the user can select and denote what their default style is. 
* Reordering feeds under "Manage feeds" should  let me grab the feed itself, not use the arrows (the arrows can be there, but I much prefer grabbing and dragging how I want it done. We should also be able to favorite feeds from here
* I should be able to multi-select to move or delete feeds under "Manage Feeds"
* Create an option in settings to enable "fetch entire article" for every feed (make any note about performance if needed, but I don't see this as a huge hit). 
* The settings menu seems.....too large on PC? I'm sure it looks fine on iOS, i'm just doing PC testing so far. 
* I should be able to resize the sidebar portion where the articles are. This can be a selectable option
* I should be able to make the story itself wider, to take up more of the screen. this can be a selectable option.
* There should only be one font selection aka Kindle menu -- where the article titles are. This should change the font for everything in Kipple, except the settings/menu. 
* When I move from any design to cards, the entire menu for sorting, layouts, kindle menu, refresh justifies to the right. This is jarring, as it's never in this spot otherwise. It needs to remain on the left. 
* If you select "magazine" while an article is open, the headlines sidebar disappears, you have to exit the article to go back. 
* Right now, "magazine" and "inbox" are way too similiar. Maybe a diff name for magazine, and some differentiation on the layout.
