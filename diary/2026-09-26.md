## Addendum: first review-PR design failed

- the owner ran `/code-review ultra 10` and got "444 files, 84,636 lines" against a limit of 8,000 lines and
  500 files. Cause: the tool diffs a PR head against `main`, ignoring the PR's own base. My PRs used a
  synthetic base, which worked in the phase 1 round but not here. I had verified the sizes with GitHub's
  own numbers and never against the tool's, which was the wrong check.
- Fix: rebuilt each PR as `main` plus only that area's files from `phase-2`, base `main`. Diff sizes are
  the same as before, and the old PRs #10 to #23 are closed. New PRs are #24 to #37.

## Addendum: phase 2 ultra review round

- the owner ran 13 cloud reviews (r1 to r8 backend, w1 to w5 web) from separate local sessions, one per branch under
  `C:\kipple-review\`. He started with $214 in credits and ended with about $17, so roughly $14 to $15 per

- I read each result from the launching local session's transcript, since cloud sessions cannot be read
  directly. Sessions ending in only a "done" line needed paging back to the actual findings.
- Signal and noise. Partial slice branches cannot build on their own, so every review reported "undefined
  symbol / missing dependency" findings that were slicing artifacts, including a claim that the API had
  lost its framing headers. An agent traced the real handler chain and disproved it, and added a test that
  pins the headers. Roughly a third of the findings across all reviews were real.
- Real bugs worth noting: image proxy missing a cross-origin header on cold responses, and a goroutine leak
  on secret rotation; WebP thumbnail memory model under-priced lossless files by 15 to 27 percent, and a
  file naming a very high group index allocated 33 MiB against a 1 MiB estimate (found by the agent while
  fixing a smaller finding); `kipple restore -` always failed, though the restore docs tell people to run
  it; an inverted highlight rule could be created but never rendered; self-closing `<video>` kept an
  insecure source; search-empty state, listen-mode not stopping speech, OPML import hiding skipped
  outlines, and a few state bugs in the web client.
- Process. I made every change; the review sessions were told nothing. Fixes ran in Sonnet worktree agents;
  the memory-safety change went through a separate Opus adversarial review with fuzzing before merging.
  The Opus review found no defects and two low gaps, which I fixed.
- Mistake, mine: my first review-PR design (synthetic base branches) was rejected because the tool diffs
  against `main` and ignores the PR base. Cost a round trip, not credits.
