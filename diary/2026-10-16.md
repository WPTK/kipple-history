# 2026-10-16 (Friday): an unattended run to 1.0.0-rc.1

On 2026-10-16 the owner asked for an unattended overnight run to reach `1.0.0-rc.1`. This entry records the plan and what the
public record shows by the end of the day. Four pull requests were opened between 23:56 and 00:01 (03:56 to 04:01 UTC on the 17th),
none merged yet. Nothing is tagged.

## The ask and the plan

- The target is `1.0.0-rc.1`, which takes bugs only (see DECISIONS, 2026-10-11).
- `0.9.0-beta.2` (#413) is folded into rc.1 instead of shipping on its own. The release commit stays unmerged.
- The remaining bugs are #406, #407, #390, #397 and #398, in three pull requests (#414, #415, #416). The documentation audit,
  issue #248, is #417.
- The full UAT, including a phone-size shakedown at iPhone 17, 17 Pro and 17 Pro Max sizes, is planned for the release candidate.
- Review rounds are capped at three per pull request. #411 went the full three rounds.

## The pull requests (all open)

- **#414** moves nine render-phase "latest value" refs in the list pane to `useLatestRef`, which writes at commit time (#407). Two
  refs, for mark-as-read-on-scroll, stay written in render. Their effect cleanup runs before the layout effects of the render
  that switched the setting, and moving them failed two existing tests. The comment says so.
- **#415** closes #397 and #398 by re-applying the closed #404 onto current main. Toasts lived in one fixed region that knew
  nothing about a screen's own bottom bar, so on Feeds and Feed Health a toast covered Select all, Move and Delete. The bar is
  now a shared `BottomBar` that publishes its height. A failed lead picture was handled separately by four layouts, and Gazette
  kept the empty box on purpose. One `ListImage` and `useImageFailure` now removes picture and frame together for every layout.
- **#416** closes #406 and #390. #406 was a timer: `focusActionsButton` re-armed a 50 ms `setTimeout` up to 20 times with no way
  to stop it, so a tick could fire after the screen unmounted and jsdom was torn down. It returns a cancel function now, and the
  hook cancels on unmount. For #390 one of four findings is a real fix (the open article, not the last-focused row, is the Tab
  stop); the other three are obsolete because the shortcuts and the Cards ring they were about no longer exist.
- **#417** closes #248. Root cause stated in the body: the README and docs carried release mechanics, design rationale and
  past-version examples that a person installing Kipple does not need. Docs only.

## What it taught

- Three of the four findings still open in #390 were made obsolete by deleting shortcuts on the 12th (and a Cards ring that no
  longer exists). Work on a bug list should start by asking which of the bugs still exist.
- A flaky test with a hanging timer is a product-shaped defect (an uncancelled retry), not a test problem. This is the second
  time this month a "flake" turned out to be a race (CHALLENGES 76).
