Scope: browser sweeps on the dev machine against throwaway instances of the 1.0.0-rc.2 binary (seeded copies, loopback only),
run by hand and never added to CI. Tracker #460, phase issue #456 (closed). No fixes in this phase.

## What the tooling taught me

- Contexts that sign in again each time register a new device; at 50 devices seen within 30 days the server refuses to save more and every
  profile write answers 404. That is the documented limit, but it made my font sweep fail until I used a fresh instance per engine.
- `networkidle` never settles (the app holds a server-sent-events connection); wait for `load` plus a short pause.
- Firefox through Playwright sometimes fails closing a context ("_maybeDontRestoreTabs"); rerun the engine.
- The `keyboard` persona found that the docs comment in #390 still mentions j/k shortcuts, which were removed on 2026-10-12.
