# 2026-10-10 (Saturday): two betas in a day, walkthrough findings, downloads that saved an error

`v0.8.0-beta.6` had been cut on the 9th (release commit #347, tag on `5b15981`). Today produced `v0.8.0-beta.7` (01:07, #352) and
`v0.8.0-beta.8` (15:23, #367, 21 changelog fragments). About 21 commits reached main. The beta.8 release also carries schema 19.

## What changed

- **Feeds (#350).** Select mode is safer: tapping a row ticks it instead of opening it, bulk delete and turn on/off show one
  progress bar, deleting a folder can delete its feeds too (you type the folder's name, and if any feed cannot be deleted the
  folder stays), and deleting feeds removes any folder that leaves empty. Never the default folder, never one that was already
  empty.
- **Downloads (#351, then #354).** OPML export, the statistics export and backup downloads sometimes saved a small error file
  named like the export. Cause and the two-step fix are in CHALLENGES 83.
- **Walkthrough findings (#353 Feeds, #355 Settings, #356 reader).** The QA walks of three areas produced three
  batches of small fixes: honest not-found states for a gone article, folder or feed, a duplicate saved search refused with a
  message naming the existing one, a toolbar that fits the narrowest phones, Back to the list after Next returning to the
  article you reached, sign-in that says how long to wait, setup wording.
- **Duplicate feeds by redirect (#359, #363).** An address that redirects to a feed you already have is refused when you add it,
  and Feed Health offers Delete this feed or Keep both when one already exists. The latter is the schema 19 change
  (`feeds.redirect_ack`, one column). Rollback is the pre-migration snapshot, as for every migration.
- **Touch targets (#362, #364).** 44 px targets on phones, layout descriptions that wrap, and a new UAT check (S8) that now fails
  when it measured nothing, after the first version could pass without checking anything.
- **Undo (#361).** An action takes its undo slot when the user acts, not when the server answers. See CHALLENGES 81.
- **Process.** Real-browser flows for Feeds, saved searches and stale addresses now run in CI (#357). The Go tests run in
  parallel and the race job is split across three runners (#358). WebKit navigation retry added (#368), later removed.
- **Docs.** The documents for whoever releases Kipple moved to `docs/maintainers/` and the release tooling to
  `scripts/maintainers/` (#348, merged on the 9th). The release gates now also check the starter feeds are alive.
- **Version path (#376, merged on the 11th).** The documented path could not hold two features that landed after beta.8, so it
  became 0.8.0 betas, then 0.9.0-beta.1, then 1.0.0-rc.N. See DECISIONS.

## What went wrong, and what it taught

- **Tests asserted what the code was written to do.** The downloads bug, selecting feeds opening them and the empty folder left
  behind all passed a green suite. #357 says so plainly: the tests built request headers by hand rather than using what browsers
  send, and `web/uat` had no Feeds flow and did not run in CI at all.
- **A fix for one symptom needed a second pass.** #351 widened the downloads rule; #354 removed it. The first was reviewed and
  correct for the cases it listed. The list was the problem.
- **The release review found things the per-PR reviews could not.** #366 carries the findings (a statistics-export queue, JSON
  Feed leniency, change notes).
- **Go CI cost.** The `go` job took about 21 minutes and could fail at random near a 15 minute per-package timeout. Profiling
  showed serial tests and one test waiting out a real network timeout, not slow code.
