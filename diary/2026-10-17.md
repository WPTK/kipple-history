# 2026-10-17 (Saturday): the 1.0.0-rc.1 candidate and the phone shakedown

The overnight run reached a release candidate on `main`. It is not tagged, released or deployed. This entry is written from the
public record only: merged pull requests and issues of the Kipple repository, and its changelog. Times are US Eastern (UTC-4).

## The candidate

- #414 to #417 (open at the end of 2026-10-16) were reviewed and merged through an integration branch, so one merge landed the
  candidate: #418, the `1.0.0-rc.1` release commit (04:10). It supersedes #413. `0.9.0-beta.2` was dropped and folded into rc.1;
  the candidate is assembled from the `0.9.0-beta.1` line plus everything merged since.
- What #414 to #417 changed: nine list refs written at commit time (#407); the focus-retry timer stopped on unmount (#406) and the
  open article as the list's Tab stop (#390); the toast above the bottom bar (#397) and no empty box for a picture that cannot be
  shown (#398); the documentation audit (#248).

## The phone-size shakedown

- Method: the app driven in a WebKit browser with iOS user agent and touch, emulating iPhone 17, iPhone 17 Pro and iPhone 17 Pro
  Max sizes (portrait, and one landscape size), on a seeded instance. Screenshots were reviewed by eye for clipped text, menu
  placement and dead ends, not just checked by script.
- #426 (06:47), phone shell fixes. Stats scrolled the whole document because the scroller had no positioning and its hidden
  tables were placed against the page. The Feeds title was squeezed to an ellipsis by text labels that appeared from 400 px wide.
  The list header jumped in height because its title row wrapped. The tab bar lit Unread for every list path, because a nav link
  only marks its own route. The reader's title and body had different widths because the measure was in `ch`, which resolves
  against each element's own font size; it is in `rem` now.
- #427 (07:01), menus and copy. The layout menu used a fixed 8 px collision padding, blind to the bottom tab bar and the
  home-indicator area; it now measures the bar when it opens. "Email - Compact" became "Headlines". The Saved searches help text
  stopped being keyboard-only wording, the Muted empty state stopped repeating its header, the Devices list puts this device first
  with an icon from the user agent, and the native number spinner is hidden in the stepper field.
- #428 (07:15), the changelog fold of the eleven fragments from #426 and #427 into the rc.1 section, plus a fix to the chrome UAT
  flow's picture check so it counts only pictures that have finished loading and only wrapper boxes.
- Lesson: several early failures were harness bugs that looked like app bugs. WebKit does not load off-screen lazy pictures, and
  two layouts put the aspect class on the `img` itself, so the picture check reported empty boxes that were not there. A probe
  that reported a clipped title (S8) was correct once the real cause was found: the title link was inline inside a truncating
  heading, so its rectangle was the unclipped text. The app was fixed, the probe was left alone.
